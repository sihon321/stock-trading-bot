<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Refreshed KIS quote/holding → KIS POST | Current broker truth can invalidate a previously eligible deterministic exit. |
| CLI SIGINT or lease state → active intraday iteration | An asynchronous stop or lost owner can otherwise race a money-moving boundary. |
| Held market source → daily evaluation ledger | A per-ticker data failure must become attributable no-trade evidence rather than a generic execution error. |
| Operational event → transition projection/notification | State evidence crosses into durable storage and optional fail-soft transport. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-11-11 | Tampering | final risk exit boundary | critical | mitigate | Re-evaluate the original deterministic exit against refreshed quote/holding truth before lease assertion, evidence, and the sole POST. |
| T-11-12 | Tampering | SIGINT and lease-loss lifecycle | critical | mitigate | Safe checkpoints, typed ownership-loss path, terminalize/reconcile/unresolved/release ordering, and injected POST-count tests. |
| T-11-13 | Repudiation | held data failure ledger | high | mitigate | Persist a date/ticker DATA_INCOMPLETE/HOLD final evaluation and sanitized ticker outcome before moving to siblings. |
| T-11-14 | Repudiation | transition projection | high | mitigate | Append every required safety event and atomically deactivate/recover superseded subject state in one transaction. |
| T-11-15 | Information Disclosure | transition/evaluation details | high | mitigate | Reuse hashed account scope, bounded stable codes, scalar sanitization, and Korean renderers; do not persist provider exceptions or raw KIS data. |
</threat_model>
