<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Broker/screener → LLM input | Authoritative numeric portfolio facts and untrusted market/news context are composed. |
| Durable daily signal → current execution | A historical same-day decision is reused under potentially changed broker/risk state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-11-08 | Replay | daily signal reuse | critical | mitigate | Date/ticker uniqueness plus mandatory current broker/risk/lease/quote/freeze/duplicate/session gates. |
| T-11-02 | Tampering | held-first universe | high | mitigate | Broker-authoritative holdings, stable ticker key, dual provenance, and global-vs-ticker incompleteness tests. |
| T-11-09 | Elevation of Privilege | prompt composition | high | mitigate | Fixed typed portfolio fields remain outside explicitly delimited untrusted news. |
| T-11-05 | Repudiation | evaluation ledger | high | mitigate | Canonical input hash committed before provider attempts and one append-only final event. |
</threat_model>
