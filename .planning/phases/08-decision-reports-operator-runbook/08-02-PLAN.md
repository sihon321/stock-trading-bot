## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite file → report models | Local files and persisted values are untrusted read inputs. |
| replay JSON → aggregation | User-selected JSON may be malformed, forged, oversized, duplicated, or incompatible. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Tampering | `ReadOnlyAuditRepository` | high | mitigate | Existing regular-file requirement, SQLite URI `mode=ro`, `query_only`, supported-version validation, explicit read transaction, bound parameters, and before/after mutation tests. |
| T-08-05 | Tampering | replay loader/aggregator | high | mitigate | Strict structure/cardinality checks, recomputed stable ID, deduplication, canonical compatibility signatures, and reject-before-aggregate ordering. |
| T-08-06 | Information Disclosure | text renderers | high | mitigate | Render normalized allowlisted fields only; bound unknown values and diagnostics; exclude secrets, raw exceptions, messages, provider payloads, and replay source bodies. |
| T-08-07 | Denial of Service | report cardinality | medium | mitigate | Validate per-result/detail cardinality, deduplicate stable IDs, reduce normalized rows separately, and fail on inconsistent counts instead of multiplying joins. |
| T-08-08 | Repudiation | summary/detail reconciliation | medium | mitigate | Derive summaries solely from immutable detail rows and assert total/determinate/state equations. |
| T-08-SC | Supply Chain | package installation | low | accept | Not applicable: no package is installed; implementation uses stdlib and already-pinned project dependencies. |
