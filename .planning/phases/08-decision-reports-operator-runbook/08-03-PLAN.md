## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → report services | Dates, database paths, replay paths, and output paths are user-controlled. |
| rendered text → filesystem | Human-readable evidence crosses into an operator-selected destination. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09 | Tampering | date/path CLI validation | high | mitigate | Strict date grammar/range checks, existing regular-file validation, no interpolated SQL, and bounded errors. |
| T-08-10 | Tampering | atomic report writer | high | mitigate | Resolved-parent containment, symlink/non-regular refusal, temp file in destination directory, fsync, atomic replace, and content-conflict tests. |
| T-08-11 | Information Disclosure | CLI diagnostics | high | mitigate | Allowlisted rendered fields and exception type plus bounded sanitized message only; never echo raw JSON, credentials, webhooks, or provider payloads. |
| T-08-12 | Elevation of Privilege | report command composition | high | mitigate | Report controllers never call `build_runtime()`, create runs, mutate policy/settings, or contact trading providers; spy tests enforce the boundary. |
| T-08-SC | Supply Chain | package installation | low | accept | Not applicable: no package install or new dependency is part of this plan. |
</threat_model>
