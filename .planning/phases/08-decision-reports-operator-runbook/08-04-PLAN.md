## Trust Boundaries

| Boundary | Description |

| settings/market/audit/order evidence → preflight | Multiple fallible sources determine whether money-moving mutation is allowed. |
| notifier transport → audit sink | External delivery result crosses into durable local evidence. |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-13 | Spoofing | mock-target identity check | high | mitigate | Typed explicit mock identity evidence; missing/mismatched/exceptional identity is UNKNOWN/BLOCK before mutation. |
| T-08-14 | Tampering | run mutation boundary | critical | mitigate | Single shared preflight result enforced before recovery/start/screen/LLM/broker/notifier calls, with zero-call spies for every non-PASS case. |
| T-08-15 | Repudiation | unresolved/duplicate order state | high | mitigate | Reduce append-only intent events, require determinate reconciliation, preserve origin/observer/duplicate links, and block affected state from new mutation. |

| T-08-17 | Denial of Service | provider/audit exceptions | medium | mitigate | Convert exceptions to explicit UNKNOWN/BLOCK with bounded diagnostics; historical read-only reports remain independently callable. |
