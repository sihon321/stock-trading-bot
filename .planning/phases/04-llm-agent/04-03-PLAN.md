## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Adapter → provider API | Prompt (with untrusted news) leaves; model output returns untrusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02 | Tampering | Malformed/adversarial provider output | critical | mitigate | Serialize-then-parse_signal on every response regardless of provider (D-05); out-of-range/malformed input proven to raise LLMProviderError in tests; strict provider schemas are first-line only |
| T-04-04 | Denial of Service (of safety) | Silent failure fabricating a signal | critical | mitigate | Typed LLMProviderError on refusal, missing tool block, None-parsed, retry exhaustion, and re-validation failure; no synthetic HOLD signal is ever constructed (D-10); reraise=True surfaces exhaustion |
| T-04-03 | Information Disclosure | structlog llm_signal_cycle line | high | mitigate | Log fields limited to provider/model/temperature/prompt_version/prompt/response/outcome; test asserts a sentinel key string never appears in captured logs; get_secret_value() not called anywhere in this plan |
