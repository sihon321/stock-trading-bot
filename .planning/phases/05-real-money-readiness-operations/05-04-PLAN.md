|----------|-------------|
| operator (terminal) → CLI | Untrusted CLI flags decide dry-run vs live and mock vs real; the real-money authorization boundary |
| CLI → broker/order path | The composition root chooses MockBroker vs KISBroker; a wrong choice trades real money |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-14 | Elevation of Privilege | real order without deliberate intent | critical | mitigate | Three independent acts: dry-run default (D-03) + config gate TRADING_MODE=real+CONFIRM_REAL_TRADING (Phase 1) + per-invocation --live-confirm (D-04); real execute refused otherwise before any place_order |
| T-05-15 | Denial of Service | one ticker error aborts the whole run | medium | mitigate | Per-ticker try/except isolation; failure captured + reported, loop continues (D-02/D-13) |
| T-05-16 | Elevation of Privilege | second KIS token flow opened by the CLI | high | mitigate | CLI owns one shared KisTokenManager passed into build_kis_broker + quote adapter (D-05/D-14) |
| T-05-17 | Repudiation | a cycle runs without an audit record | high | mitigate | start_run + per-ticker write_decision inside the loop; audit is authoritative even if notify fails |
</threat_model>
