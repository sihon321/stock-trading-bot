<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env/.env to `Settings` | Untrusted operator-provided environment values become runtime config. |
| `Settings` to logs/banner/errors | Secret-bearing config is summarized for operator visibility. |
| `Settings` to future adapters | Future KIS and LLM adapters will depend on selected active config. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Information Disclosure | `startup_banner`, `repr(Settings)`, validation diagnostics | high | mitigate | Use `SecretStr`, allowlisted banner fields, and tests that assert fake secrets never appear in banner/repr/log diagnostics. |
| T-01-05 | Tampering | `Settings.active_kis` | high | mitigate | Model mock and real as whole `KisCredentialGroup` objects and expose a derived active group selected only by `TradingMode`. |
| T-01-06 | Elevation of Privilege | `TRADING_MODE=real` | high | mitigate | Validator rejects real mode unless `CONFIRM_REAL_TRADING=yes`; tests cover failure and success. |
| T-01-07 | Denial of Service | LLM provider secret validation | medium | mitigate | Require only the selected provider's secret so a missing inactive provider key cannot block startup. |
</threat_model>
